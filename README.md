# Jev Resume Filler

Chrome 简历自动填写扩展。它基于Jev动态选择招聘网站可选的section，将本地保存的结构化简历资料与其相对应，程序化填写到招聘网站的表单中，并在填写后回读页面结果。最终预览、提交和投递始终由用户操作。

## 核心能力

- 填写个人信息、教育、实习、工作、项目、家庭成员、奖项、语言、技能与附件。
- 支持输入框、下拉、日期、搜索选择器、协议勾选、上传、重复经历和常见 iframe 表单。
- 新增经历时识别页面是直接新增、打开编辑器还是跳转编辑页，再继续填写。
- 保留网页已有内容；本地资料与页面已有值冲突时，记录待补原因供用户确认。

               │

│ - 输出统一 recordIndex        │
└──────────────┬──────────────┘
               │ Snapshot
               ▼
┌─────────────────────────────┐
│ 分区计划器 jev-client.js      │
│ 代码生成有限候选：            │
│ - 进入 section                │

│ - 填写 / 选择 / 上传          │
│ - 返回 / 暂存待补 / 退出      │
│                               │
│ Jev 只在候选动作中选择下一步  │

               │ Jev Choice

               │

Jev 仅在代码生成的有限候选中选择下一步；简历字段匹配、具体值写入、页面回读和最终投递保护由代码负责。

## Instructions：快速配置

### 1. 安装与加载

```bash
git clone <repository-url>
cd jev-resume-filler
npm install
```

在 Chrome 打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择克隆后的项目根目录。修改代码后，在扩展详情页点击“重新加载”，再刷新招聘网站页面。

### 2. 配置 Jev 与简历

1. 点击工具栏中的扩展图标，打开“设置”。
2. 填写 `TypeSafe Jev API Key`，点击“保存 Key”。
3. 在弹窗填写资料，或导入基于 [data/resume-default.json](data/resume-default.json) 的简历 JSON。
4. 选择头像、生活照和简历附件后，点击“保存简历”。

API Key 和个人简历资料保存在本地；`.gitignore` 默认排除真实资料与照片。

### 3. 让 Agent 初始化 JSON

将你的简历文件和 [data/resume-default.json](data/resume-default.json)、[data/resume-schema.json](data/resume-schema.json) 一并交给支持文件读取与修改的 Agent，并使用下面的提示词：

```text
请把我提供的简历转换为符合 resume-schema.json 的严格 JSON。
以 resume-default.json 为字段模板，保留所有字段与数组结构。请先提取所有可确认信息；对姓名、联系方式、教育、经历、日期、证书、奖项、家庭成员等未提供或含糊的信息，主动逐项向我确认。收到我的答复后，再填空字符串或空数组；不要猜测或编造。
日期使用 YYYY-MM-DD；只有年月时写 YYYY-MM-01；“至今”保留为“至今”。
教育、实习、工作、项目、获奖等每一段经历都单独放入数组。
确认完成后输出仅包含 JSON，不要 Markdown、解释或代码块。
```

保存 agent 的输出为本地 `.json` 文件，再通过“设置 → 导入 JSON”导入。完整解析规则见 [prompts/resume-parse-prompt.md](prompts/resume-parse-prompt.md)。

### 4. 使用

1. 登录目标招聘网站，并进入可编辑的简历页面。
2. 打开扩展，核对资料与附件状态。
3. 如需勾选协议或真实性声明，先在扩展内确认。
4. 点击“开始自动填写”，查看运行日志与待补项。
5. 人工核对后，自行完成最终投递。

## 安全边界

- 扩展不会点击“提交”“投递”“预览并提交”等最终动作。
- 不自动覆盖网页已有内容。
- 无法匹配或缺少资料的字段会保留，并在日志中说明原因。
